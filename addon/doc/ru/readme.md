# Проверка VirusTotal (vtChecker)

* Автор: Author Name
* Совместимость с NVDA: 2024.1.0 и выше

Это дополнение позволяет проверить выбранный файл в проводнике Windows через базу данных VirusTotal.

## Настройка
1. Получите бесплатный API ключ на [VirusTotal](https://www.virustotal.com/).
2. Откройте Настройки NVDA -> VirusTotal.
3. Вставьте ваш API ключ.

## Использование
Зайдите в Настройки NVDA -> Жесты ввода -> VirusTotal, и назначьте комбинацию клавиш для "Checks the focused file with VirusTotal".
* Одно нажатие: Краткий отчет (соотношение обнаружений) и копирование в буфер обмена.
* Двойное нажатие: Открывает подробное окно с результатами всех антивирусов.
