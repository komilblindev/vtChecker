# VirusTotal Checker

* Автор: Komil Hamzayev <hamzayevkomil52@gmail.com>
* Совместимость с NVDA: 2024.1.0 и выше

Это дополнение позволяет легко проверять файлы, URL-адреса или хэши с помощью VirusTotal API.

## Настройка
1. Зарегистрируйте бесплатную учетную запись на [VirusTotal](https://www.virustotal.com/).
2. Перейдите в свой профиль (Profile) -> Ключ API (API Key) и скопируйте свой ключ.
3. Откройте Настройки NVDA -> VirusTotal, вставьте свой ключ API и настройте параметры (автоматическая загрузка, звуковые сигналы и т. д.).

## Использование и горячие клавиши
По умолчанию горячие клавиши не назначены. Вы должны назначить их вручную:
1. Перейдите в **Меню NVDA -> Параметры -> Жесты ввода**.
2. Разверните категорию **VirusTotal**.
3. Назначьте сочетания клавиш для следующих команд:
   * **Проверить файл в фокусе:** Проверяет выбранный в данный момент файл в проводнике Windows.
   * **Диалог ручной проверки:** Открывает диалоговое окно для ручного ввода URL-адреса, IP-адреса или хэша SHA-256.

### Проверка файла
Когда вы нажимаете горячую клавишу на файле:
* **Однократное нажатие:** NVDA объявляет краткую сводку (например, 0/91), и полный подробный отчет со ссылкой на VT копируется в буфер обмена.
* **Двойное нажатие:** Открывает окно просмотра, содержащее полный подробный отчет всех антивирусных систем.

Если файл совершенно новый для VirusTotal, дополнение может автоматически загрузить его (если включено в настройках), дождаться очереди в фоновом режиме и уведомить вас, как только результаты будут готовы.


### API Limits
Примечание: Стандартный бесплатный API VirusTotal допускает до 4 запросов в минуту и 500 запросов в день. Вы можете проверить текущее использование лимита в настройках дополнения.
